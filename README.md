Jogo do mario

Este é um projeto acadêmico desenvolvido como parte da disciplina de Front-End, no curso de Análise e Desenvolvimento de Sistemas da UNINASSAU.

O projeto consiste na reprodução de um mini jogo inspirado no clássico Super Mario, seguindo o vídeo tutorial original disponível no YouTube (https://www.youtube.com/watch?v=r9buAwVBDhA&t=1s). Foi desenvolvido com HTML, CSS e JavaScript, com foco na prática de animações, manipulação de eventos e interatividade em páginas web.
